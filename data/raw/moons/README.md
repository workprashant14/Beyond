# Planetary satellite physical parameters

`satellites.csv` is copied unchanged from https://github.com/devstronomy/nasa-data-scraper (data/csv/satellites.csv,
commit f311254c444585e40a8ebbff76ef2b8d785af438, MIT licence, see LICENSE-MIT). That project scrapes NASA/JPL's
"Planetary Satellite Physical Parameters" table (https://ssd.jpl.nasa.gov/sats/phys_par/).
Units: GM km^3/s^2, radius km, density g/cm^3, magnitude (band letter V/R where given), geometric albedo.
Values written without "±" carry no stated uncertainty in the source table (adopted or assumed values).
